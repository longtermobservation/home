Long-Term Observation: Humans
Website README

This website supports the Long-Term Observation: Humans field guide series.

The content hosted here documents prolonged exposure to Earth-based domestic life,
human social behavior, and cumulative environmental burden under sustained gravity.

This site is intentionally minimal.
No tracking, no accounts, and no dynamic content are required for observation.

Files may be updated, expanded, or reorganized without notice.
Continuity is maintained where practical.
